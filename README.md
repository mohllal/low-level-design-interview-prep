# Low-level design interview prep

Personal reference notes for low-level design interviews. The material is selected for what is useful in the interview — a process step, a piece of modeling vocabulary, a principle worth invoking to justify a decision, or a pattern worth reaching for under time pressure — rather than for complete coverage of any subject.

## Conventions

- Code samples are Python with type hints throughout.
- Diagrams are Mermaid where it renders well, and Markdown text where it does not.
